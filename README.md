# Advanced Security Hardening and Auditing Tool (Linux)

## 📌 Overview
This is a beginner-friendly **Linux Security Hardening and Auditing Tool**.  
It helps check for:
- System updates
- Firewall status
- Sudo usage logs

The goal is to provide a **simple tool** for learning and practicing Linux security basics.

---

## ⚡ Features
- Detects your package manager (APT or Pacman).
- Checks for pending updates.
- Verifies firewall status.
- Audits sudo usage logs.
